# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository when available. If private reporting is unavailable, open a minimal issue asking for a private contact path without publishing exploit details or secrets.

High-value security reports include credential exposure, persona-seed exposure, physical-CID leakage, unsafe updater path handling, arbitrary update-source injection, checksum bypass, and failures that can leave the installed NRO unrecoverable.

Do **not** post passwords, authentication tokens, Authorization headers, persona seeds, physical CID values, or private Remote credentials in public issues.

PersonaFoil's persona system is an application-level compatibility/privacy feature; it is not a hardware security boundary and does not replace Nintendo platform identity mechanisms.
